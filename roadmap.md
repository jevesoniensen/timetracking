# Roadmap

## Automated GitHub Releases

Want it on the GitHub Releases page instead?

If you also want GitHub to automatically publish a permanent downloadable `.zip` under `https://github.com/jevesoniensen/timetracking/releases` whenever you push a version tag (e.g., `git tag v1.0.0 && git push --tags`), add a release step (`softprops/action-gh-release`) to `.github/workflows/build-windows.yml`.
